# Arcade_Pooyan — Basys 3 Porting Specification

Target: Digilent Basys 3 (`xc7a35tcpg236-1`), Vivado 2020.2, VHDL target language.

## 1. Upstream Source

- **Repository**: [darfpga/Arcade_Pooyan](https://github.com/darfpga/Arcade_Pooyan)
- **Original board**: Intel/Altera DE10-Lite (MAX 10 `10M50DAF484C7G`)
- **Core clock**: 12 MHz (video), 14 MHz (sound board)
- **ROMs**: `pooyan.zip` from MAME

## 3. Build Workflow

### Step 1: `make setup`
- Sanity-checks key source files
- Applies `arcade_pooyan_t80_xor_width.patch` to `rtl_t80_350/T80.vhd`
- Copies `.xpr` and `XDC` to `basys3/`
- Generates `basys3/arcade_pooyan_basys3.vhd` via embedded-patch script
- Copies wrapper into Vivado project directory structure
- Runs `prep_roms` to generate VHDL PROM files from ROM zip

### Step 2: `make clk_wiz`
- Creates clk_wiz_0 MMCM IP stubs
- Real IP must be generated by Vivado (run in Vivado GUI or batch mode)

### Step 3: `make patch`
- Regenerates the Basys3 wrapper via `make_de10_lite_to_basys3_patch.sh`

### Step 4: `make synth`
- Resets `synth_1` run and launches synthesis
- Runs from `/tmp` to keep `vivado.log`/`vivado.jou` outside the repo

### Step 5: `make bitstream`
- Runs implementation + `write_bitstream`

## 4. Clock Architecture

```
100 MHz (sys_clk)
  └── clk_wiz_0 (MMCM)
        ├── 12.288 MHz (clock_12) → core video
        └── 14.318 MHz (clock_14) → sound board + PWM audio

clock_12 → /2 → clock_6 → scandoubler ce_x1 + PS/2 keyboard clock
```

## 5. Dip Switch Mapping

| Switch | Function | Dip Switch |
|--------|----------|------------|
| sw(0)  | Lives bit 0 | dip_switch_2(0) |
| sw(1)  | Lives bit 1 | dip_switch_2(1) |
| sw(2)  | Cocktail mode | dip_switch_2(2) |
| sw(3)  | Bonus | dip_switch_2(3) |
| sw(4)  | Difficulty bit 0 | dip_switch_2(4) |
| sw(5)  | Difficulty bit 1 | dip_switch_2(5) |
| sw(6)  | Difficulty bit 2 | dip_switch_2(6) |
| sw(7)  | Sound | dip_switch_2(7) |
| sw(8)  | Coinage A bit 0 | dip_switch_1(0) |
| sw(9)  | Coinage A bit 1 | dip_switch_1(1) |
| sw(10) | Coinage A bit 2 | dip_switch_1(2) |
| sw(11) | Coinage A bit 3 | dip_switch_1(3) |
| sw(12) | Coinage A bit 4 | dip_switch_1(4) |
| sw(15:13) | (unused) | dip_switch_1(7:5) = "111" (Coinage B default) |

Default (all switches down): Lives=3, Cocktail=Upright, Bonus=50K/80K+, Difficulty=Easy, Demo Sounds=ON.
Coinage A: 1 coin / 1 credit. All-down = DE10-Lite defaults (`X"FF"` / `X"7F"`).

## 6. Input Mapping

### PS/2 Keyboard (JB Pmod)
| Key | Function |
|-----|----------|
| F3 | Add coin |
| F4 | Start 1 player |
| F5 | Start 2 players |
| F8 | Toggle display mode (31 kHz VGA / 15 kHz TV) |
| SPACE | Fire |
| RIGHT | Rotate right |
| LEFT | Rotate left |
| UP | Rotate up |
| DOWN | Rotate down |

### Joystick (JA Pmod, active-low)
| JA Pin | Function |
|--------|----------|
| JA1 (J1) | Right |
| JA2 (L2) | Left |
| JA3 (J2) | Down |
| JA4 (G2) | Up |
| JA7 (H1) | Fire |

Combo mappings (OR-merged with keyboard):
- Start1 = Fire + Left
- Start2 = Fire + Right
- Coin = Fire + Up

## 7. VGA Output

- 12-bit VGA (4 bits per R/G/B channel)
- Scandoubler: DECA `vga_scandoubler.v` (used directly, no patches needed)
- Input: core's 3/3/2-bit RGB padded to 6 bits by MSB replication
- Output: 31 kHz VGA (scandoubled 15 kHz core output)
- F8 key toggles display mode:
  - Default (F8 off): 31 kHz scan-doubled VGA
  - F8 on: 15 kHz TV (native core RGB, composite sync on HS, VS held high)

## 8. Audio

- 11-bit audio from `pooyan_sound_board`
- PWM accumulator clocked at 14 MHz
- Output via PmodAMP2 on JC Pmod: AIN (JC1), GAIN (JC2, sw15), SHUTDOWN (JC4, sw14)

## 9. Patches Required

### T80 XOR Width Fix (`arcade_pooyan_t80_xor_width.patch`)
- **File**: `rtl_t80_350/T80.vhd` line 737
- **Change**: `(ioq and x"7")` → `(ioq and '0'&x"07")`
- **Reason**: Vivado rejects mismatched operand widths in logical AND
- Applied during `make setup`

### Basys3 Wrapper (`arcade_pooyan_de10_lite_to_basys3.patch`)
- **Base**: `rtl_dar/pooyan_de10_lite.vhd` (DE10-Lite wrapper)
- **Target**: `basys3/arcade_pooyan_basys3.vhd`
- Generated by `make_de10_lite_to_basys3_patch.sh` during `make setup`

## 10. Vivado Project

- `.xpr` references `$PPRDIR/../` for all RTL files (one level up from `basys3/`)
- Scandoubler referenced directly: `$PPRDIR/../deca/vga_scandoubler.v`
- Top module: `arcade_pooyan_basys3`
- Part: `xc7a35tcpg236-1`

## 11. Critical Warnings

- None expected. T80 patch resolves the only Vivado synthesis error.
- `dp` constraint in XDC is commented out (unused 7-segment decimal point).
